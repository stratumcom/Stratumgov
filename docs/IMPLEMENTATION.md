# Implementation notes

The workspace was empty. The app uses Next.js App Router, strict TypeScript, Tailwind CSS, shadcn CLI components, Lucide, React Hook Form, Zod, React Email and Resend. npm is the package manager.

The original direction is dark green, ivory and muted gold with local business photography and local fonts. Pages use server components except interactive navigation, filters, accordions, sharing and forms.

Reference research: https://dcsl.com.ng/ was read on 9 October 2026. Its service families, separate service pages, company navigation and enquiry paths informed the content hierarchy. https://soccompliance.com/ returned a 403 access block in direct requests and could not be visually reviewed. No reference branding, text, source or exact layout is reused.

Service areas are explicitly proposed and `confirmed: false`. Articles are explicitly sample editorials, not verified publications. Unconfirmed details and draft legal pages are noindexed and excluded from the sitemap. No invented registration details, addresses, staff, clients, awards or credentials are published.

No live email delivery is claimed without a configured Resend account and verified sender. Public form success is only returned when Resend accepts the owner notification; acceptance is not a guarantee of inbox placement. Production forms fail closed if verified email configuration, shared rate limiting or a trusted client IP is unavailable.

Local assets are downloaded from Unsplash and Google Fonts. Photos depict illustrative workplaces and people, not the company's premises or staff. See `public/images/README.md` and `public/fonts/README.md` for sources.
